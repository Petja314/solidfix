# SolidFix — Next.js

Сайт SolidFix перенесён на Next.js App Router. В `public/` находятся фотографии проектов, отзывы и выбранное фото для Hero; изображения сохранены без изменений.

## Запуск на компьютере

Нужен Node.js версии 20.9 или новее.

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

## Сборка и размещение на хостинге

```bash
npm run build
```

Готовый сайт появится в папке `out/`. Загрузите **содержимое** этой папки в корневую папку сайта на хостинге — обычно это `public_html`, `www` или `htdocs`. Текущая версия использует WhatsApp-ссылки и не содержит серверной формы или базы данных, поэтому ей подходит обычный хостинг статических файлов.

## Основные файлы

- `app/page.tsx` — секции и текст сайта
- `app/globals.css` — оформление и адаптивная верстка
- `components/Carousel.tsx` — отдельные слайдеры проектов и отзывов
- `data/slides.ts` — изображения слайдеров и описания
- `public/` — фото Hero, проекты и отзывы

Чтобы добавить проект, положите его фото в `public/projects/` и добавьте запись в `data/slides.ts`.
